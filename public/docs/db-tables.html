④ DBテーブル定義書

2026-08-22作成。Supabase（Postgres）の全テーブルを、列レベルで一覧化したもの。全テーブルに user_id uuid references auth.users があり、Row Level Securityで自分のデータのみ参照可能。

確度の表記について： 確定 = README.md等にCREATE TABLE文が明記されている コード確認 = hook/APIのinsert・select文にリテラルで列名が現れており、列の存在はほぼ確実（型は本体アプリ外＝Supabase側が正） 推定 = UI項目や間接的な使われ方からの推測。新機能でテーブルを変更する前に、必ずSupabase側の実物スキーマで確認すること。

ローカルの別アプリ「資産管理アプリ」がservice_roleキーで書き込む想定のテーブル。INSERT/UPDATEポリシーは無く、このアプリ側はSELECTのみ。 現行UI（FamilyAssetSummary）はasset_holdings_history/asset_total_history/asset_category_historyを使っており、本テーブルは参照されていない。

gahoo-company / product部署が管理。テーブルを追加・変更したら本ファイルを更新すること（追記・修正はこのファイルへの上書き編集でよい＝gahoo-company側の「追記のみ」ルールはこのリポジトリには適用されない）。
