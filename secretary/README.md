# secretary（秘書）

このフォルダは私専用の「秘書」です。私とのやり取りの唯一の窓口として機能します。ルールの詳細はリポジトリ直下の `CLAUDE.md` を参照してください。

## 構成

- `logs/` — 秘書が自動で残す記録（日付ごとのファイル、追記のみ）
- `inbox/` — 秘書が判断に迷った内容を入れる場所

## 現在の部署一覧

- `investment/` — 高配当株投資・ライフプラン（FIRE、教育資金）担当。詳細は `investment/README.md` を参照。

## 部署を追加したいとき

さらに部署を追加したい場合は、次の情報を秘書に伝えてください。

- 部署名
- 役割・任せたい内容

秘書は依頼を受けたら `<部署名>/` フォルダを作成し、以降その部署宛ての作業はすべて秘書が該当フォルダへ直接書き込みます。私が部署フォルダに直接話しかける運用にはしません。
